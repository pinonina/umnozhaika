# Доработка «Умножайки»

Ты помогаешь развивать «Умножайку» — тренажёр таблицы умножения для детей 7–10 лет, в том числе детей с ОВЗ. Главное в проекте — методика: ребёнок понимает умножение через картинки, а не зубрит. Любая доработка не должна ломать методику.

## Как устроен проект

- Весь тренажёр — один файл `index.html`: HTML, CSS, JavaScript и картинки (встроены в файл). Не дели его на несколько файлов и не подключай внешние библиотеки и картинки по ссылкам: тренажёр должен открываться двойным кликом и без интернета.
- Сервера и базы данных нет. Ничего не отправляй в интернет и не собирай данные о ребёнке.
- Есть столбики ×2 и ×5.

## Методика (не ломать)

1. **Три ступеньки картинок** для каждого столбика, строго по порядку:
   - тарелки с предметами;
   - точки столбиками со скобками;
   - числовой луч.
2. **Переход вверх** — после двух уверенных ответов подряд на текущей ступеньке.
3. **Шаг назад** — если ребёнку понадобилась подсказка.
4. **Счёт нажатием по группам**: ребёнок сам отсчитывает группы, ответ не показывается сразу.
5. **Осьминожка Умножайка** реагирует на ответы своими эмоциями. Ошибка — это не наказание: никаких красных крестов, звуков ошибки и потери очков.
6. **Озвучка** 🔊 работает через голос браузера для каждого нового текста задания.
7. Между заданиями есть **физминутка**, на главном экране — ссылка **«Для взрослых»**.

## Как добавить новый столбик

1. Найди, как в коде описаны существующие столбики ×2 и ×5, и сделай новый по тому же образцу.
2. Для нового столбика должны работать все три ступеньки картинок, переход вверх и шаг назад.
3. Добавь кнопку столбика на главный экран в том же стиле, что «Умножаем на 2» и «Умножаем на 5».
4. Обнови текст на экране «Для взрослых», если там перечислены столбики.
5. Рекомендуемый порядок новых столбиков: ×9, ×4, ×3, затем остальные.

## Правила текста для детей

- Короткие предложения, простые слова, обращение на «ты».
- Одна инструкция за раз.
- Хвалить за старание, а не только за правильный ответ.

## Проверка перед выкладкой

Открой `index.html` в браузере и пройди вручную:

- [ ] главный экран, все кнопки столбиков;
- [ ] каждая из трёх ступенек картинок для изменённого столбика;
- [ ] правильный ответ, неправильный ответ, подсказка и шаг назад;
- [ ] озвучка 🔊;
- [ ] физминутка и экран «Для взрослых»;
- [ ] вид на узком экране телефона (в браузере: F12 → режим мобильного устройства).

## Выкладка новой версии

1. Сохрани изменения в git и отправь в репозиторий:
   ```
   git add index.html
   git commit -m "Коротко: что изменилось"
   git push
   ```
2. На хостинге Beget: панель → «Файловый менеджер» → папка сайта → `public_html` → заменить `index.html` новым файлом.
3. Открыть сайт с телефона без VPN и проверить, что открылась новая версия.
